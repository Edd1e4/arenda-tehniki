## Что делает пакет
stage.sh проверяет контрольные суммы, Node, свободное место и отсутствие конфликтов; создаёт отдельную служебную учётную запись без входа, каталоги приложения и данных, устанавливает две отдельные службы systemd. Он не включает службы и не меняет Nginx, DNS, сайт, существующих агентов или их службы.
activate.sh — отдельный шаг после согласованного переноса настроек и остановки локального бота. Включает запуск при старте сервера и перезапуск при ошибке.
Код: /opt/arenda24mo/app. Данные: /var/lib/arenda24mo. Секреты: /etc/arenda24mo.

## Секретов в архиве нет
Для работы потребуется отдельно и с разрешения владельца перенести:
- локальный .env в /etc/arenda24mo/claude.env;
- локальный .env.telegram в /etc/arenda24mo/telegram.env;
- data/telegram-state.json в /var/lib/arenda24mo/telegram-state.json, чтобы сохранить разрешённый личный чат;
- data/orders.json в /var/lib/arenda24mo/orders.json, чтобы сохранить текущий журнал и нумерацию.
Эти файлы содержат API-ключи, идентификаторы чата и сведения заявок. Их нельзя отправлять в GitHub, публичный архив или текст чата. Переносить через защищённое подключение или приватный файловый интерфейс Webdock, не печатать содержимое в логах.
До остановки локального бота обеспечить свежую копию журнала и состояния; окончательный перенос делать после остановки, чтобы не пропустить новые записи.

## Выполнение
1. Передать исходный архив на сервер и распаковать в новую отдельную папку.
2. Просмотреть скрипты и выполнить stage.sh от root.
3. По согласованию перенести настройки и данные, сохранив локальную копию.
4. Остановить локальную копию бота через Ctrl+C. Не запускать два getUpdates-процесса для одного токена.
5. Выполнить activate.sh от root.
6. Проверить обе службы, затем личное сообщение /help и учебную заявку в Telegram. После перезапуска диспетчера проверить журнал.
7. Проверить службу через несколько минут: мгновенный active не доказывает устойчивую работу Telegram и доступность внешнего API.

## Доступ к журналу
Он остаётся на 127.0.0.1:4388 сервера. Прямой публичный доступ не включён. Для просмотра с компьютера нужен SSH-туннель с локальным свободным портом, например 4389:
ssh -N -L 4389:127.0.0.1:4388 admin@193.181.221.93
Затем открыть http://127.0.0.1:4389/orders.
Способ входа SSH следует проверить отдельно; новые ключи доступа пакет не создаёт.
Домен arenda24mo.ru не меняется. Публичный сайт и публичный приём клиентов этим пакетом не включаются.

## Остановка и возврат к локальному тесту
Остановить только arenda24mo-telegram.service и arenda24mo-dispatcher.service. Отключить их автозапуск. Не удалять данные.
Перед возвращением на Windows перенести свежие данные обратно по отдельному согласованию; старый локальный журнал не заменяет новые серверные записи.
Только после остановки серверного бота запускать локальную копию.
