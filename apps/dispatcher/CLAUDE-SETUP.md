# Пробный текстовый диспетчер Claude

Статус: код подключения подготовлен. Реальный запрос с ключом пользователя ещё не выполнен. Телефон, Telegram, WhatsApp, MAX, СМС не подключены. Есть локальное сохранение заявок: см. JOURNAL.md.

## Локальный запуск
Требуется Node.js 22 или новее.
1. Скопировать .env.example в .env в этой папке.
2. Добавить ключ только в .env после ANTHROPIC_API_KEY=. Указать доступную модель в CLAUDE_MODEL. Пример идентификатора: claude-haiku-4-5-20251001; доступ проверяется реальным запросом.
3. Из этой папки выполнить:
```sh
node --env-file=.env server.mjs
```
4. Открыть напечатанный локальный адрес.
5. Использовать учебные данные. Каждая отправка передаёт историю в Anthropic и расходует API-баланс.

Ключ читается сервером из окружения. Он не возвращается браузеру, не должен быть в коде или GitHub. .gitignore исключает .env; .env.example содержит только пустые значения.

## Проверка
```sh
node --test intake.test.mjs claude.test.mjs
```
Тесты Claude используют фиктивный ответ провайдера и запросы в памяти без сети. Проверяются схема, ошибки, ограничения ввода, локальный доступ, отсутствие ключа в ответе. Это не проверка качества извлечения данных живой моделью или реального HTTP-соединения.

## Ограничения
- Сервер слушает только 127.0.0.1. Не выставлять этот тестовый сервер в интернет.
- Фронтенд ведёт историю только в памяти вкладки; сервер сохраняет заявку в локальный файл только по отдельному нажатию кнопки «Сохранить заявку в журнал».
- Claude извлекает факты, а ответы формируются проверяемыми правилами. Это разговорный сбор заявки, не универсальный чат.
- Зона не определяется моделью. Проверка маршрута, габаритов, цены и наличия всегда остаётся человеку.
- Максимум 24 сообщения в запросе, 4 000 символов в одном сообщении, 12 запросов в минуту; по одному запросу одновременно.
- На стороне Anthropic действуют его условия обработки данных. До приёма реальных заявок нужны согласование хранения, защита сервиса, проверка обработки контактов и тесты живых диалогов.
