# Локальный журнал заявок

## Как пользоваться
1. Запустить локальный сервер по CLAUDE-SETUP.md.
2. В диалоге уточнить адреса, вес, длину/ширину/высоту, количество мест, дату, время и контакт.
3. Проверить черновик и нажать «Сохранить заявку в журнал». До нажатия запись не создаётся.
4. Открыть /orders через ссылку «Открыть журнал заявок».
5. Выбрать запись, указать технику и итоговую стоимость, статус «Рассчитана», сохранить.
6. После реального согласования с клиентом и проверки маршрута, габаритов, доступа и наличия поставить обе отметки и статус «Подтверждена». Это ручная отметка: клиенту ничего не отправляется.

## Данные и ограничения
- Файл: data/orders.json относительно папки диспетчера. В GitHub не передавать; data/ исключена из Git.
- Файл содержит контакты и адреса, не зашифрован и защищён только доступом к компьютеру. Отдельного пароля нет; сервер слушает 127.0.0.1.
- Сохраняются структурированные сведения черновика, без текста всей переписки и без API-ключа.
- Черновики до сохранения живут только в памяти сервера, до 30 минут; после перезапуска нужно подготовить черновик заново. Сохранённые заявки сохраняются.
- Повторное сохранение одного черновика возвращает ту же заявку. После нового диалога создаётся новый черновик.
- Согласование стоимости и проверка условий записываются оператором. Изменение цены/техники после подтверждения требует возврата в «Рассчитана» и повторного согласования.
- Смена статуса не вызывает бронирование внешней техники, звонки, отправку сообщений или СМС.
- Одновременно запускать только один сервер для этого файла. Тестовый журнал не предназначен для публикации в интернете.

## Проверка
Из корня репозитория:
```sh
node --test apps/dispatcher/intake.test.mjs apps/dispatcher/claude.test.mjs apps/dispatcher/orders.test.mjs
```
Тесты используют учебные данные и отдельные временные папки test-data-*; API Claude в тестах не вызывается.
